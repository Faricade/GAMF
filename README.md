# GAMF

Generic Arkanoid Made in [Foster](https://github.com/FosterFramework/Foster).  
The very first and worst of my game projects, written to learn game architecture basics (scenes, entities, collision).  
Doesn't even use any kind of engine or game library, except for base framework.

## How to Run

You can grab a built version in [Releases](https://github.com/Faricade/GAMF/releases).  
I give no guarantee that it will run, though.

## How to Build
### Don't.
  
But if you really want to, you'll need: 
- .NET 10 SDK
- A local clone of Foster at `../Foster` relative to this project

Just build and run  
Controls: Left/Right arrow keys to move the paddle, Up to restart/launch the ball.
